내 자료실

로그인한 사용자에게만 서버 API가 학습용 가상 메모를 제공합니다.

자료 API는 서버에서 로그인 토큰을 검증합니다. 로그인하지 않으면 자료를 반환하지 않습니다.

설치 및 기기 승인 상태

기기 승인 상태: 확인되지 않음 (서버 검증 정보 미제공)

홈 화면에 설치하거나 로그인해도 기기 승인이 완료되는 것은 아닙니다. 보호 요청의 허용·거부는 기존 서버와 보안 판정기가 결정합니다.

연결 상태 확인 중...

브라우저 메뉴에서 ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택할 수 있습니다. 지원 여부는 브라우저마다 다릅니다.

오프라인에서는 안내 화면만 볼 수 있으며 메모·로그인·기기 확인은 사용할 수 없습니다.

1~11단계 정상·금지 요청 실측 표

각 단계 정상·금지 1행씩. 기대 결과와 실제 HTTP 상태, 요청 ID(브라우저 생성), 확인 시각을 기록합니다. 운영 실행이 불가능한 항목은 미실행으로 남깁니다. 별도 41종 공식 시험은 미검증이며 통과로 계산하지 않습니다.
